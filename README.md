# vibecast
Transmissao de jogos de baixa latencia integrada ao Discord via Vencord, com backend baseado em Sunshine/Vibeshine.

## Planejamento

O [plano do protótipo](docs/plano-do-prototipo.md) organiza o trabalho da [issue #1](https://github.com/rubimpassos/vibecast/issues/1) em etapas de validação, implementação e aceite.

## Viabilidade

O [inventário inicial](docs/inventario-e-viabilidade.md) registra revisões, pontos de integração e lacunas encontradas no código. Os [experimentos](experiments/README.md) incluem sondas passivas para a build instalada e o renderer do Discord, com testes locais e roteiro para os dois PCs Windows.
